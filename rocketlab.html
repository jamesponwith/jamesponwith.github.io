RocketLab: a liquid rocket engine design platform

Oct 27, 2026 · 5 min read

TL;DR
  • A physics model of a liquid rocket engine that couples every discipline that sets real performance, from equilibrium thermochemistry to stage payload, so an optimiser can't win by violating physics somewhere else.
  • Against six flight engines (RS-25, RD-180, Merlin 1D, RL10B-2, Raptor 2, Vulcain 2), modelled Isp is within 1.8% and mass within 12%.
  • Optimising 34 architectures for stage payload, full-flow staged combustion comes out best for every propellant, but by 0.3–1%, which is within model uncertainty. The same Python runs in the browser through Pyodide.

Engine design is a coupled problem. Chamber pressure sets Isp, but also the heat flux the regenerative cooling has to carry, which sets the coolant pressure drop, which sets the pump power the cycle has to find, which sets turbine temperature and engine mass, which feed back into what the stage can lift. A model that optimises any one of these in isolation will find designs that don't close. RocketLab chains them and returns the constraint violations along with the performance.

The model chain

  • Thermochemistry. NASA 7-term polynomials and Gibbs minimisation by the RP-1311 (CEA) element-potential Newton method, including condensed-phase carbon for fuel-rich kerosene gas generators. Pre-computed (O/F, Pc, ε) maps answer queries with under 0.05% interpolation error.
  • Nozzle. Rao thrust-optimised bells, cones, Angelino aerospike plugs with altitude compensation, and a Schmucker separation check at the deep-throttle point.
  • Cooling. A 1-D counter-flow regen march with a calibrated Bartz gas side, Peng-Robinson real-fluid coolants through the pseudo-critical region, coolant-specific Nusselt laws, film cooling, coking and decomposition limits, and channel-width limits for additively manufactured liners.
  • Cycles. Pump and turbine power balance for pressure-fed, electric-pump, gas-generator, expander, fuel- and ox-rich staged, and full-flow staged combustion, with preburner gas from equilibrium at the turbine temperature limit.
  • Rotating detonation. Chapman-Jouguet detonation, with the pressure gain expressed as an equivalent chamber pressure and a realisation factor ηpg (0 = no gain, 1 = ideal; default 0.35).
  • Stage. Trajectory-averaged Isp, engine count from lift-off T/W, tank mass from propellant density and tank pressure, then Δv, or payload at a required Δv.

Isp is within 1.8% for all six (Raptor 2 vacuum is the worst case) and mass within 12% (RD-180). Ideal Isp matches CEA within 0.5%, and Chapman-Jouguet velocities for H₂/O₂ and CH₄/O₂ match the literature within 0.1%. The test suite (44 tests) pins these as regressions.

These are engineering-fidelity models for conceptual and preliminary design, not CFD. Several pieces are calibrated to flight-engine data: the Bartz coefficient (×0.82), the finite-rate kinetic loss correlation, a ×0.7 separation knock-down on Schmucker for thrust-optimised bells, and plumbing and controls mass. Coolant transport properties near the pseudo-critical point are approximate (±15–20%).

Full-flow staged combustion wins for every propellant, but its margin over the next-best cycle is 0.3–1%, inside the model's uncertainty, so the ranking is a lean rather than a verdict. Kerosene is capped by coking.

In the browser

The live site runs the unmodified Python package in a web worker through Pyodide (CPython, NumPy and SciPy in WebAssembly): design, sweeps, validation and optimisation. The architecture trade studies are precomputed and published as a report. Locally, the first run builds the thermochemistry maps with the full equilibrium solver, about 20 s per propellant pair, and caches them in ~/.cache/rocketlab.

Run it

python -m venv .venv && .venv/bin/pip install numpy scipy pytest
.venv/bin/python -m rocketlab serve            # web dashboard at http://127.0.0.1:8765
.venv/bin/python -m rocketlab validate         # model vs RS-25, RD-180, Merlin, RL10, Raptor, Vulcain
.venv/bin/python -m rocketlab analyze --fuel LCH4 --cycle ffsc --pc 300 --of 3.6 --eps 34
.venv/bin/python -m rocketlab optimize --cycle ffsc --stage booster --objective payload
.venv/bin/python scripts/run_trades.py all     # booster + upper-stage trade studies -> results/
.venv/bin/python -m pytest tests               # 44 validation / regression tests
