DORA metrics, in public

Deploy frequency, lead time, change-failure rate, MTTR — collected weekly from the GitHub API by each repo's learn.yml and committed as dora.json. Its git history is the trend line. Part of the agentic flywheel — read the writeup.

Deploy frequency
Production deploys per week; repos that record none fall back to published releases.
Lead time
Median hours from the earliest commit since the previous deploy to this one going live.
Change-failure rate
Failed changes / deploys (or releases). A change failed if its deploy failed, or if an incident-labeled issue opened while it was live; several incidents on one deploy count once.
MTTR
Median hours from an incident issue opening to closing.

snapshots update weekly (monday 06:00 UTC) · incidents = issues labeled incident
